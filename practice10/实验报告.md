# 练习 10 实验报告

## 一、实验名称
DragAndDraw 自定义触摸绘图视图

## 二、实验目的
1. 理解 Android 自定义 View 的基本结构。
2. 掌握 `onDraw()` 与 `onTouchEvent()` 的配合方式。
3. 熟悉通过 `Canvas`、`Paint` 和触摸事件动态绘制图形。

## 三、实验环境
- 开发工具：Android Studio / Gradle
- 开发语言：Java
- 基础项目：`29_TouchEvents`
- 完成项目：`practice10/DragAndDrawCustomView`

## 四、实验内容与实现过程
本次实验参考《Android 编程权威指南》第 29 章内容，实现一个可响应触摸拖拽的自定义视图。程序启动后显示 `BoxDrawingView`，用户在屏幕上按下并拖动时，应用记录起点和当前触摸点，并根据两点形成的边界实时绘制图形。

根据题目效果图要求，本次实现将背景颜色设置为 `0xffff7256`，将图形颜色设置为 `0x221E1E1E`。其中图形颜色使用 ARGB 模式，透明度较低，因此多个图形重叠时会产生更深的叠加效果。

在绘制逻辑上，`BoxDrawingView` 维护一个 `List<Box>` 保存已经创建的图形。`ACTION_DOWN` 时创建新的 `Box`，`ACTION_MOVE` 时更新当前 `Box` 的终点并调用 `invalidate()` 触发重绘，`ACTION_UP` 或 `ACTION_CANCEL` 时结束当前图形绘制。`onDraw()` 中遍历所有 `Box`，根据起点和终点计算边界，并使用 `canvas.drawOval()` 绘制半透明椭圆。

## 五、关键功能
- 自定义 `BoxDrawingView` 并在布局 XML 中直接使用。
- 使用 `MotionEvent` 处理按下、移动、抬起和取消事件。
- 通过 `invalidate()` 实现拖动过程中的实时刷新。
- 使用 `Canvas.drawOval()` 绘制椭圆图形。
- 使用 `0xffff7256` 背景色和 `0x221E1E1E` 半透明图形色匹配题目效果。
