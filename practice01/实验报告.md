# 上机 1 实验报告

## 一、实验名称
Number Game

## 二、实验目的
1. 熟悉 Android Studio 工程结构与运行方式。
2. 掌握按钮点击事件、随机数生成、计分逻辑和 Toast 提示的基本用法。
3. 通过一个小型交互程序理解界面状态更新过程。

## 三、实验内容
本次提交重点完成题目中的 Number Game。程序运行后会随机生成两个 100 以内且不相同的整数，显示在两个按钮上。用户点击较大的数字时分数加 1，并弹出 `Correct`；点击错误时分数减 1，并弹出 `Wrong`，随后自动进入下一轮。

## 四、实现思路
1. 在 `MainActivity.kt` 中使用 Compose 搭建主界面。
2. 使用 `Random.nextInt(100)` 生成两个不相同的随机数。
3. 维护 `points`、`leftNumber`、`rightNumber` 三个状态。
4. 每次点击按钮时比较所选数字与 `maxOf(leftNumber, rightNumber)`，更新得分并弹出提示。
5. 完成当前轮次后立即刷新为下一组数字。

## 五、核心实现
- 主代码文件：`NumberGame/app/src/main/java/com/example/test01/MainActivity.kt`

- 主要功能：随机出题、分数统计、结果提示、界面实时刷新
