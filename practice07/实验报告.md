# 上机 7 实验报告

## 一、实验名称
CriminalIntent Toolbar Icons and Implicit Intents

## 二、实验目的
1. 掌握为工具栏菜单项添加自定义图标的方法。
2. 理解在 Fragment 中创建菜单项并处理删除操作的实现方式。
3. 掌握通过隐式 Intent 选择联系人和发送文本报告的基本流程。
4. 熟悉在 SQLite 数据仓库中新增删除数据操作。

## 三、实验内容
本次实验以 `CriminalIntent` 项目为基础，实现了以下功能：

1. 为 `CrimeListFragment` 的 New Crime 菜单项添加自定义图标 `ic_action_add`。
2. 为 `CrimeFragment` 的 Delete Crime 菜单项添加自定义图标 `ic_action_delete`。
3. 在 `CrimeLab` 中增加 `deleteCrime(Crime crime)` 方法，并在 `CrimeFragment` 菜单中调用它删除当前 crime，随后结束当前详情页面。
4. 通过隐式 Intent 实现选择嫌疑人和发送 Crime Report 的功能。

## 四、实现思路
1. 以 `15_ImplicitIntents` 工程为基础复制出 `practice07/CriminalIntentToolbarIntents`，复用数据库、联系人选择和报告发送功能。
2. 在 `res/drawable/` 中新增两个 vector 图标资源：
   - `ic_action_add.xml`
   - `ic_action_delete.xml`
3. 修改 `fragment_crime_list.xml`，将 `menu_item_new_crime` 的图标替换为 `@drawable/ic_action_add`。
4. 修改 `crime.xml`，新增删除菜单项，并在 `CrimeFragment` 中通过 `setHasOptionsMenu(true)`、`onCreateOptionsMenu()` 和 `onOptionsItemSelected()` 处理删除逻辑。
5. 在 `CrimeLab` 中通过 SQLite 的 `delete()` 删除指定 UUID 对应的 crime 记录。

```bash
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew assembleDebug
```

## 七、实验总结
通过本次实验，我把工具栏图标、SQLite 删除操作和隐式 Intent 三部分内容整合到了 `CriminalIntent` 项目中。相比之前只做“查看和修改”操作的版本，这次项目增加了“删除”和“与系统应用交互”的能力，也让我更清楚地理解了 Fragment 菜单、联系人选择和文本分享的实现方式。
