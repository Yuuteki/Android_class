# 练习 9 实验报告

## 一、实验名称
PhotoGallery 项目添加 WebView 原图预览功能

## 二、实验目的
1. 理解 Handler/HandlerThread 项目中图片列表加载流程。
2. 掌握从 JSON 数据中解析额外字段并传递给界面组件的方法。
3. 学习使用 `WebView` 在应用内部加载网页或图片 URL。

## 三、实验环境
- 开发工具：Android Studio / Gradle
- 开发语言：Java
- 基础项目：`24_Handlers`
- 参考章节：第 28 章 WebView
- 完成项目：`practice09/PhotoGalleryWebView`

## 四、实验内容与实现过程
本次实验在图片瀑布流列表的基础上增加原图预览功能。首先在 `GalleryItem` 中新增大图链接字段，并提供获取 `Uri` 的方法。随后在 `FlickrFetchr` 解析 Pixabay 返回的 JSON 数据时，除原有缩略图 `previewURL` 外，也读取 `largeImageURL` 字段并保存到 `GalleryItem` 中。

界面交互方面，`PhotoGalleryFragment` 的 `PhotoHolder` 保存当前绑定的 `GalleryItem`。当用户点击缩略图时，程序通过 `PhotoPageActivity.newIntent()` 把大图链接作为 Intent data 传入新的页面。

新增的 `PhotoPageActivity` 继续复用项目中的 `SingleFragmentActivity` 结构，负责承载 `PhotoPageFragment`。`PhotoPageFragment` 中包含 `WebView` 和水平进度条，页面加载时通过 `WebChromeClient` 更新加载进度，通过 `WebViewClient` 保证链接在应用内部打开，最后调用 `mWebView.loadUrl()` 加载被点击图片对应的 `largeImageURL`。

## 五、关键功能
- 从 JSON 中解析 `largeImageURL` 原图链接。
- 点击缩略图后跳转到原图预览页面。
- 使用 `WebView` 在应用内部加载原始图片链接。
- 使用 `ProgressBar` 显示 WebView 加载进度。
- 在 Manifest 中注册 `PhotoPageActivity`，并保留网络权限。

## 七、实验总结
通过本次实验，我理解了从网络 JSON 数据到 RecyclerView 列表，再到详情页面跳转的数据传递过程。`WebView` 可以让应用不离开自身界面就展示网页或远程图片，配合 Intent data 和 Fragment 参数使用，能够比较清晰地完成列表项详情展示。
