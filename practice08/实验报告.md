# 练习 8 实验报告

## 一、实验名称
BeatBox 项目添加 SoundPool 播放功能并定制主题样式

## 二、实验目的
1. 理解 Android assets 资源目录的使用方式。
2. 掌握 `SoundPool` 加载、播放短音频资源的基本流程。
3. 学习通过主题、样式和颜色资源统一调整应用界面。

## 三、实验环境
- 开发工具：Android Studio / Gradle
- 开发语言：Java
- 基础项目：`18_Assets`
- 完成项目：`practice08/BeatBoxSoundPoolStyle`

## 四、实验内容与实现过程
本次实验以 `18_Assets` 工程为基础，首先在 `BeatBox` 类中创建 `SoundPool` 对象，并设置最大同时播放数量。程序启动后通过 `AssetManager` 读取 `sample_sounds` 目录中的 wav 音频文件，再使用 `AssetFileDescriptor` 将每个音频加载进 `SoundPool`，并把返回的 `soundId` 保存到对应的 `Sound` 对象中。

在列表界面中，`BeatBoxFragment` 为每个按钮绑定点击事件。用户点击某个声音按钮时，程序调用 `mBeatBox.play(mSound)`，根据保存的 `soundId` 播放对应音频。为了避免资源泄漏，在 Fragment 销毁时调用 `mBeatBox.release()` 释放音频资源。

界面定制方面，新增并修改了颜色、主题和按钮样式资源。RecyclerView 设置了浅色背景和内边距，声音按钮统一使用深色背景、白色文字、非全大写文字和轻微阴影，使界面比原始模板更完整。

## 五、关键功能
- 使用 `SoundPool` 加载 assets 中的短音频。
- 为 `Sound` 增加 `soundId` 字段保存加载结果。
- 点击 RecyclerView 中的按钮即可播放对应音效。
- 在生命周期结束时释放 `SoundPool`。
- 使用 `colors.xml` 和 `styles.xml` 完成主题与按钮样式定制。

## 六、实验结果
项目已完成练习要求，能够正常编译生成 Debug APK。验证命令如下：

```bash
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew assembleDebug
```

编译结果：`BUILD SUCCESSFUL`。

## 七、实验总结
通过本次实验，我熟悉了 assets 文件读取、`SoundPool` 音频加载播放以及 Android 样式资源的使用。相比直接在代码中设置界面属性，把颜色和按钮效果抽取到资源文件中更方便维护，也更符合 Android 项目结构。
